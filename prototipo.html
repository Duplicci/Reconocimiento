Cómo conectar

  1. Inicia el servidor con iniciar_veriface.bat (o ejecuta python scanner_server.py).
  2. El QR abre en el teléfono la dirección de red del computador; no escribas localhost en el teléfono.
  3. Conecta ambos dispositivos a la misma Wi-Fi y escanea el QR.
  4. En el teléfono, permite el acceso a la cámara y toma una foto. El panel la detecta y compara localmente con el directorio.
  5. Si Windows lo solicita, permite Python en la red privada del Firewall.
La cámara se activa en el teléfono mediante el selector nativo de iOS/Android. El tráfico local usa HTTP sin cifrado: utiliza una Wi-Fi privada de confianza y no publiques el puerto en Internet.

Contexto no seguro (file://)
Los navegadores solo permiten getUserMedia en https:// o http://localhost. Si abriste el HTML con doble clic, la cámara nunca mostrará imagen.
cd ruta/del/proyecto
python -m http.server 8080
# abre http://localhost:8080
Permiso denegado u otra app usa la cámara
Comprueba el candado de la barra de direcciones, cierra Zoom/Teams/Meet y vuelve a intentarlo. En macOS: Ajustes › Privacidad › Cámara.
about:settings/content/camera
